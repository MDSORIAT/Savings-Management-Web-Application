Digital Samiti একটি Group Savings Management Web Application। এখানে সদস্যরা একটি গ্রুপ তৈরি করতে পারবে, গ্রুপে Join করতে পারবে, নির্দিষ্ট পরিমাণ টাকা Contribution করতে পারবে এবং নির্ধারিত নিয়ম অনুযায়ী Group Fund Distribution পরিচালনা করতে পারবে।

### 4. Main Application Workflow

1. User registers.
2. User logs in.
3. User creates a group or joins an existing group.
4. Group Admin approves members.
5. Group rules are finalized.
6. Members start contributing.
7. Member clicks Send Money.
8. Supported Bank App opens, or transfer instructions appear.
9. Member submits payment proof if required.
10. Authorized Admin verifies the payment.
11. Payment status changes to PAID.
12. Payouts are managed according to the approved group rules.

### 5. Important Payment Rule

Opening a Bank App does not confirm a successful transfer.

The system must use verified bank information, an authorized payment provider, or manual payment verification.

A group must not use an unapproved lottery or fund distribution model.

## PART B: ENGLISH DOCUMENTATION (IELTS 5.0 LEVEL)

### 1. Project Introduction

Digital Samiti is a group savings management web application.

It helps people create savings groups, join groups, pay regular contributions, and manage group money records.

The application will be designed mainly for users in Japan.

### 2. User Roles

There are three main user roles:

1. Super Admin
2. Group Admin
3. Group Member

### 4. Main User Process

1. A user creates an account.
2. The user logs in.
3. The user creates or joins a group.
4. The Group Admin approves the members.
5. Members follow the group rules.
6. Members make their monthly contributions.
7. A member clicks the Send Money button.
8. The supported Bank App opens.
9. The member sends money through the bank.
10. The member submits payment proof if needed.
11. An authorized person checks the payment.
12. The system updates the payment status.
13. The group manages its payout schedule.

### 5. Main Goal

The main goal is to make group savings easy, clear, and safe.

Every member should be able to see their contributions, payment records, and group information.
