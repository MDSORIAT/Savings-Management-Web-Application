### 6. File Management Rules

Project Files:
- Component Files
- Page Files
- Model Files
- Controller Files
- Route Files
- Utility Files

Uploaded Files:
- Profile Pictures
- Payment Receipts
- Support Attachments

File Management Rules:

1. প্রতিটি File নির্দিষ্ট Folder-এ রাখতে হবে।
2. File Name পরিষ্কার ও অর্থবহ হতে হবে।
3. JavaScript File-এর জন্য .js অথবা .jsx ব্যবহার করতে হবে।
4. Sensitive Files Public Folder-এ রাখা যাবে না।
5. Secret Files GitHub-এ Upload করা যাবে না।
6. Payment Receipts Private Storage-এ রাখতে হবে।
7. অপ্রয়োজনীয় Files Delete করতে হবে।
8. একই কাজের জন্য Duplicate Files তৈরি করা যাবে না।

Production-এ Uploaded Files-এর জন্য Private Object Storage ব্যবহার করা ভালো। Railway-এর সাধারণ Application Filesystem-এর ওপর স্থায়ী File Storage হিসেবে নির্ভর করা যাবে না।

### 7. Environment Variables

Frontend .env.example:

VITE_API_URL=http://localhost:5000/api

Backend .env.example:

PORT=5000

NODE_ENV=development

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

FRONTEND_URL=http://localhost:5173

EMAIL_HOST=your_email_host

EMAIL_USER=your_email_user

EMAIL_PASSWORD=your_email_password

FILE_STORAGE_BUCKET=your_private_bucket

সব Real Secret Railway Variables বা Local Environment-এ রাখতে হবে।

.env File GitHub-এ Upload করা যাবে না।

Frontend-এ শুধু Public Configuration থাকবে। Database URL, JWT Secret, Email Password এবং Storage Secret কখনো Frontend-এ রাখা যাবে না।
