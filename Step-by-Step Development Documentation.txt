## PART B: ENGLISH DOCUMENTATION (IELTS 5.0 LEVEL)

### 1. Development Goal

This document explains how to build the Digital Samiti web application step by step.

The project will be divided into different development phases.

Each phase must be completed and tested before moving to the next phase.

### 2. Development Phases

**Phase 01: Project Planning**
- Finalize project requirements.
- Define user roles.
- List all pages.
- Plan the database.
- Prepare the development plan.

**Phase 02: UI/UX Design**
- Design the website layout.
- Create the dashboard.
- Design forms and buttons.
- Make the website mobile-friendly.

**Phase 03: Project Setup**
- Create a GitHub repository.
- Create frontend and backend projects.
- Install required packages.
- Configure environment variables.
- Set up Git.

**Phase 04: Frontend Development**
- Build the Home Page.
- Build Login and Registration.
- Build the Dashboard.
- Build Group Pages.
- Build Contribution Pages.
- Build Admin Pages.

**Phase 05: Backend Development**
- Create the Express server.
- Connect MongoDB.
- Create models and routes.
- Create controllers.
- Create middleware.
- Handle errors.

**Phase 06: Authentication**
- Create user registration.
- Create login.
- Hash passwords.
- Add JWT authentication.
- Add password reset.

**Phase 07: User Roles**
- Create Admin, Group Admin, and Member roles.
- Control user permissions.
- Protect private routes.

**Phase 08: Group Management**
- Create groups.
- Join groups.
- Approve members.
- Manage group information.
- Manage group rules.

**Phase 09: Contribution System**
- Create contributions.
- Set payment deadlines.
- Track payment status.
- Save contribution history.
- Upload payment proof.

**Phase 10: Bank App Integration**
- Create the Send Money button.
- Add supported Bank App links.
- Add fallback instructions.
- Add a payment reference.
- Add manual payment verification.

**Phase 11: Payout Management**
- Create payout schedules.
- Track payout status.
- Record approved payouts.
- Show payout history.

**Phase 12: Notifications**
- Add payment reminders.
- Add group notifications.
- Add payment status messages.
- Add email notifications.

**Phase 13: Admin Dashboard**
- Manage users.
- Manage groups.
- Verify payment proofs.
- Review reports.
- Manage complaints.

**Phase 14: Testing**
- Test frontend and backend.
- Test APIs.
- Test database operations.
- Test user permissions.
- Test mobile design.
- Test security.

**Phase 15: Deployment**
- Upload code to GitHub.
- Connect GitHub with Railway.
- Deploy the backend.
- Connect MongoDB.
- Configure environment variables.
- Deploy the frontend.
- Add HTTPS and a domain.

**Phase 16: Final Review**
- Fix bugs.
- Check security.
- Check database backups.
- Review the complete application.
- Prepare the final release.

### 3. Development Rules

- Complete each phase carefully.
- Test every important feature.
- Save code changes with Git.
- Keep secret keys private.
- Test security before launch.
- Do not use real money without legal approval.

### 4. Final Result

After completing all phases, Digital Samiti will be a working group savings management web application.
